# Kamchi — "האור נדלק" · build brief for module agents

Repo `/home/user/Kamchi` — Next.js 15 (app router), React 19, TypeScript strict, Tailwind v4 (CSS-first tokens in `src/app/globals.css`), pnpm.
A pitch demo of a new website + designer portal for **Kamchi Lighting (קמחי תאורה)**, Israel's leading importer of designer lighting (founded ~80 years ago by Avraham Kamchi as a workshop in south Tel Aviv; second generation runs it, the third is joining; 5,000 m² showroom at Lehi 23, Bnei Brak, next to the Design Center; Dun's 100). Brands: Artemide, Vibia, Bomma, Terzani, Panzeri, Fabbian, Exenia, Ole, Neko, Cangini & Tucci, Dechem, Icone, Avolux, Vesoi, Aldo Bernardi, Swarovski lighting. Reference projects: Google Israel offices, Airport City, the Migdal tower in Petah Tikva, Cinema City, Mercedes showrooms, Isrotel headquarters, homes by leading Israeli interior designers. An "architects and designers club" of ~60 studios that today is only a list of names. The demo goes unsolicited to a family that sells Artemide: the craft must be at the level of the brands they carry (Awwwards Site-of-the-Day bar).

## Concept
**Everything starts unlit. Scrolling, hovering and tapping are the only switches. Light is the only decoration**: no decorative gradients, no illustrations, no stock photos, no icon packs, no emoji. Fixtures are procedural `FixtureArt` on black; glow is layered radial gradients (CSS) or WebGL. Lights switch on with a **120 ms incandescent ramp, never a fade**. Page transitions are 240 ms blackouts. Motion is slow and physical.

## Tokens & type
- Colours (Tailwind classes): `bg-night` #050505, `bg-charcoal` #141414, `ash` #3A3A3A (lines/surfaces only, never text), `text-paper` #F2EEE6, `text-muted` #A9A59D (8.3:1), `text-brass` #B8955B (7.3:1 on night only), `text-brass-light` #C9A86B (brass text on charcoal), glow = `text-glow` / `bg-glow` / `border-glow` / `shadow-glow` → CSS `rgb(var(--glow-rgb) / a)`. `--glow-rgb` is re-tinted by the 2700K/3000K/4000K control, so **never hardcode #FFD9A8 for anything that glows**.
- Type: `.font-display` = David Libre (Hebrew display, large and quiet; Cormorant Garamond when `:lang(en)`), Heebo = default UI, `.font-mono` / `.num` = IBM Plex Mono for lumens, kelvin, prices, ids, dates. Headline scale: `text-4xl md:text-6xl lg:text-7xl`, weight 400, tight leading.
- Layout: `.container-x`, generous whitespace, hairlines (`.hairline`, `.brass-rule`, `.brass-line`), `.panel` surfaces, no rounded-xl cards, no drop shadows except glow, tabular numbers.

## RTL & language
Default `dir="rtl"`, `lang="he"`. Use logical utilities only (`ps- pe- ms- me- start- end- text-start`, `inset-inline-start`), never `left/right/pl/pr` unless the thing is intentionally directional (a slider). Every visible string is bilingual: `const t = useTx(); t({ he: "…", en: "…" })` (client) or `tx(lang, {...})`. Shared labels live in `src/lib/i18n/common.ts` (`FIXTURE_TYPE_LABEL, SPACE_LABEL, DIMMING_LABEL, LEAD_TIME_LABEL, ORDER_STATUS_LABEL, PROJECT_STATUS_LABEL, FINISH_LABEL, FINISH_HEX, SHOWROOM, ADDRESS, BETA, SIMULATION, DEMO_PRICE, NAV, PORTAL_NAV`). Money: `formatIls(n, lang)`; numbers `formatNumber`; dates `formatDate/formatTime`. **Hebrew must be natural, modern, professional Israeli Hebrew in the design-trade register** (פס צבירה, גוף תאורה, שקוע תקרה, עמעום, טמפרטורת צבע, חדר רחצה, זמן אספקה, הצעת מחיר), never calqued from English, no superlatives, no marketing fluff. Mono values stay LTR (`dir="ltr"` on spans like `1800 lm · 2700K`).

## Primitives you must reuse
- `<SwitchOn on? delay glow glowSize glowOffset hover offOpacity as>` — the switch. Lights on entering the viewport (or when `on` is true), runs the 120 ms ramp, honours "הכול דלוק" automatically. `<Glow shape="pool|cone|halo|wash|spot|diffuse" size x y opacity>` — layered glow. `<FixtureArt fixture lit cast suspension/>` — the fixture portrait. `<KelvinToggle/>`.
- CSS: `.switch-on/.is-on`, `.lit-hover`, `.glow--*`, `.panel`, `.hairline`, `.brass-rule`, `.brass-line`, `.lit-text`, `.eyebrow`, `.btn .btn-primary .btn-brass .btn-sm`, `.field`, `.chip[aria-pressed]`, `.badge-beta`, `.skeleton` (designed warm sweep), `.flash-warm` (1.2 s warm flash), `.blackout`.
- Motion: Lenis + GSAP are wired; `getGsap()` from `src/lib/motion/gsap.ts` returns `{gsap, ScrollTrigger}` registered. Framer Motion is available. `useReducedMotion()` is true under `prefers-reduced-motion` **or** "הכול דלוק": then no scroll-driven or timed animation, everything lit instantly. `useInView`, `useMedia/useIsDesktop/useFinePointer/useLowPower`, `useHydrated`.
- Navigation: `<TransitionLink>` (240 ms blackout) instead of `<Link>` for in-app links.
- UI: `PageHeader` (eyebrow/title/lede/actions/beta), `Dialog` (native `<dialog>`), `Skeleton`.
- Store (`src/lib/store/index.ts` — **read it fully; do not modify it**): `useStore` (persisted + synced across tabs via BroadcastChannel), `useModeStore` (per-tab designer/kamchi), selectors (`selectCartCount, selectUnseenForDesk, selectUnseenForDesigner, selectStudioProjects, selectOpenRequests`), `useLiveFixture(id)` (stock/lead-time overlays). Persisted state arrives after mount: use `useHydrated()` and render `.skeleton` blocks until true for anything reading projects/quotes/cart/events.
- Data (`src/lib/data`): `FIXTURES, BRANDS, STUDIOS, SEED_PROJECTS, getFixture, getFixtureBySlug, getBrand, getStudio, fixturesByBrand, featuredFixtures`; types in `src/lib/types.ts`; demo files at `/demo-files/spec-sheet.pdf`, `/demo-files/fixture.ies`, `/demo-files/fixture.dxf` (label "DWG/DXF (הדגמה)").
- PDF: `generateQuotePdf({quote, project, studio, lang, getFixture})`, `downloadBytes`, `bytesToObjectUrl` in `src/lib/pdf/quote-pdf.ts`.

## Accessibility (WCAG 2.0 AA / ת״י 5568)
Text on black ≥ 7:1 (paper / muted / brass-light; never ash). Every control keyboard-operable with visible focus (global `:focus-visible` glow exists), real `<button>`/`<a>`, labels and `aria-*`, headings in order (one h1 per page), no information by colour alone (pair with text), hover reveals also work on focus and are visible under "הכול דלוק", `prefers-reduced-motion` respected, live regions (`aria-live="polite"`) for things that arrive (desk inbox, chat answers), images/SVG have `alt`/`aria-label` or `aria-hidden`.
